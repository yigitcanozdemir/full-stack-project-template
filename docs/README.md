# Documentation

What to read for which question. Each folder answers one kind of question, and a page belongs in
exactly one of them.

| You want to… | Read |
|---|---|
| Know what we are building, for whom, and why | [`product/`](product/README.md) — idea, PRD, research |
| Understand how the system works and why | [`architecture/`](architecture/README.md) |
| Know why a decision was made, and what it rules out | [`adr/`](adr/README.md) — one decision per record |
| See what is being built now, and what is done | [`plans/`](plans/README.md) |
| Write docstrings, comments, or a new page | [`guides/documentation.md`](guides/documentation.md) |
| Start a page from a template | [`templates/`](templates/) — system page, package README, runbook |
| Fix something broken in a running system | `runbooks/` — created with the first runbook |

The rules for agents and contributors are in the root [`AGENTS.md`](../AGENTS.md) and the nearest
`AGENTS.md` to the code being changed.
